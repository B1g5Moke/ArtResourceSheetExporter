# Art Resource Sheet Exporter

Unity Editor 单脚本工具：扫描 Texture、特效 Prefab、Spine `SkeletonDataAsset`、FBX/模型动画和 Animator Controller，整理名称、分类和参考图，并导出 `.xlsx` 美术资源表。

当前公开版版本号：`v0.4.1`。这是与内部版**独立维护**的发布目录；不要把上级目录中的测试截图、日志、公司项目资源或个人配置一并上传。

想了解扫描、分类、预览和 Excel 生成的实现，可阅读[实现原理笔记](./实现原理笔记.md)。

## 安装

1. 只复制 [`ArtResourceSheetExporter.cs`](./ArtResourceSheetExporter.cs) 到项目的 `Assets/Editor` 目录。
2. 等待编译完成，从 `TA工具 → 美术资源表导出工具 v0.4.1` 或 `Tools → Art Resource Sheet Exporter v0.4.1` 打开。
3. 若项目安装了 Spine-Unity，工具会自动识别 `SkeletonDataAsset` 并生成 Spine 预览；若没有安装，Spine 功能自动停用，其他资源功能仍可使用。工具不附带 Spine 插件或项目美术资源。

Spine 资源的导出版本须与项目中的 Spine-Unity 版本匹配。本脚本在不引用 Spine 程序集的编译环境，以及使用 Spine-Unity 4.1、3.8 的本地项目中通过编译。反射版的实际 Spine 预览图仍应在目标 Unity 项目中逐项检查；目前不宣称所有 Unity、渲染管线和 Spine 组合都已完成运行时验证。

## 基本用法

拖入资源或文件夹 → 检查识别结果 → 按需调整名称、分类、说明、排序或参考图 → 导出 Excel。分类文件夹和前缀、动画名称规则均可在窗口里编辑。新安装时采用更通用的示例分类：游戏内（`Gameplay` / `game_`）、主菜单（`MainMenu` / `menu_`）、结算界面（`Results` / `result_`）、加载界面（`Loading` / `load_`）、通用资源（`Common` / `common_`），另有“未分类”兜底。这些并非行业统一命名，可按项目实际目录改动。

窗口右上角可切换“中文 / English”；选择会保存在本机 Unity `EditorPrefs`。语言切换只改变界面文字和内置分类的下拉显示，不会翻译或改写资源名称、规则名称、说明以及导出的 Excel 内容。识别设置和批量编辑可折叠，导入、整理与保存、资源列表按操作顺序排列。

若工具检测到旧版**完全未修改**的老虎机分类预设（普通游戏、免费游戏、彩金游戏、加载界面、未分类，以及对应旧文件夹和前缀），会自动换成通用预设并重新识别当前列表；确认结果后点击“保存全部配置”。只要名称、顺序、文件夹或前缀有一项被用户改过，就视为自定义规则并完整保留。也可在“游戏分类”设置中主动点击“载入通用预设”。

可手动指定参考图。特效会尝试渲染指定时间的画面；某些自定义 Shader、粒子和透明混合模式可能仍需手动参考图。Animator 图可自动绘制；原生 Animator 窗口截图依赖 Unity 编辑器内部接口与窗口状态，建议逐项检查截图结果。

排序和资源配置保存在当前电脑的 Unity `EditorPrefs` 中，不会随着脚本或 GitHub 仓库同步到其他电脑。`.xlsx` 由脚本直接生成，不需要额外的 Excel 第三方库。

## 导出的工作簿

- `美术资源表`：保留 A～E 的类型、名称、输出名、说明、参考图，按分类插入合并标题行，适合看图核对和美术评审。图片仍锚定到对应 E 列单元格；小图不放大，大图超出 Excel 单元格上限时等比例缩小。因为有合并标题，这一页不设置自动筛选。
- `资源索引`：同一批资源的扁平清单，一项一行。包括序号、游戏分类、资源类型、名称、输出名、Unity 路径、文件格式、预览尺寸、说明、资源标识、留空并用浅黄底标出的审核状态列；冻结前三列和表头，可直接筛选、排序、补充审核结果。预览尺寸表示导出预览 PNG 的尺寸，不一定是原资源尺寸；资源标识通常是 GUID + localFileIdentifier，旧 Unity 会使用兼容键。重新导出同名文件会覆盖在 Excel 中手工填写的审核状态，请先另存或备份。
